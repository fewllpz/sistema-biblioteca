# Telas do Sistema

## Tela de Login

Permite que o usuário informe seus dados para acessar o sistema.

## Tela Inicial

Apresenta as principais funções do sistema.

## Tela de Cadastro de Livros

Permite cadastrar novos livros no sistema.

## Tela de Consulta

Permite pesquisar livros e verificar sua disponibilidade.

## Tela de Empréstimo

Permite registrar o empréstimo de um livro para um usuário.

## Tela de Devolução

Permite registrar a devolução de um livro.
