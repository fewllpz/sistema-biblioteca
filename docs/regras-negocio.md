# Regras de Negócio

## RN01

Um usuário não poderá realizar um novo empréstimo caso possua algum livro em atraso.

## RN02

Um livro que já esteja emprestado não poderá ser emprestado novamente.

## RN03

Somente usuários cadastrados poderão realizar empréstimos.

## RN04

A devolução deverá ser registrada no sistema.

## RN05

O sistema deverá informar quando um livro não estiver disponível.
