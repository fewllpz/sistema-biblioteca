# Arquitetura do Sistema

O sistema será organizado em três partes principais.

## Interface

Responsável pela interação com os usuários.

## Sistema

Responsável pelas regras de negócio e pelo processamento das informações.

## Banco de Dados

Responsável por armazenar os usuários, livros e empréstimos.

## Estrutura

```text
Usuário
   ↓
Interface
   ↓
Sistema
   ↓
Banco de Dados
```
