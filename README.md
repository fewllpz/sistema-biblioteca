# 📚 Sistema de Biblioteca

## Sobre o projeto

O Sistema de Biblioteca foi desenvolvido para facilitar o controle de livros, usuários, empréstimos e devoluções de uma biblioteca.

## Objetivo

Criar um sistema que permita organizar o acervo da biblioteca e facilitar o controle dos empréstimos e devoluções.

## Problema

O controle manual de livros e empréstimos pode causar perda de informações, atrasos e dificuldade para localizar livros.

## Público-alvo

* Bibliotecários
* Funcionários
* Alunos

## Funcionalidades

* Cadastro de usuários
* Cadastro de livros
* Consulta de livros
* Registro de empréstimos
* Registro de devoluções
* Controle de livros disponíveis
* Relatórios
